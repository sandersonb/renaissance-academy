# Renaissance Academy Enrollment — Documentation

Guides for the three audiences of the enrollment system.

| Guide | For | Start here |
|---|---|---|
| **[IT Guidebook](it/)** | Technical staff / IT admins | Deploying, upgrading the database, nginx + TLS, CLI reference |
| **[Admin Staff Guidebook](admin/)** | Enrollment office staff (non-technical) | Using the admin portal day to day |

These documents are safe to share and contain **no passwords, keys, or personal
data**. Real credentials live only in server environment configuration.
