# Paperwork, surveys & reports

## Registration paperwork (the Paperwork page)

Admitted and returning families download registration **PDF packets** from their
parent portal, fill them out, and **email or hand-deliver** them to the enrollment
specialist. (For privacy, completed forms are **never uploaded back through the
website** — that's intentional.)

Your job on the **Paperwork** page is to keep the *blank* packets current. There's
one slot for each packet:

- **Family Packet** (new families) and **Family Packet (returning families)**
- **Kindergarten Packet** and **1st–9th Grade Packet**

For each slot you can:

- **Upload / replace** — choose a PDF to become the current version. Re-upload each
  year to publish the new forms.
- **Preview** — the filename link opens the current file.
- **Remove** — delete the uploaded file.

If a slot hasn't been uploaded yet, a **sample default** packet is served so
families never hit a broken link — the page shows *"sample default — upload to
replace"* as a reminder to post the real one. Only PDF files are accepted.

Families only ever see the packets they actually need (their grade's packet, and
the correct family packet for new vs. returning), based on their students'
statuses.

## Survey questions

The questions families answer come in two kinds:

- **Registration questions** — asked of a student when a family accepts an offer
  (for example, kindergarten session or language preference). These can be
  grade-specific.
- **Lottery questions** — asked once, at sign-up (for example, how they heard about
  the school).

On the **Survey Questions** page you can add and edit questions, set the input type
(short text, long text, single-choice, multiple-choice, date), add/edit the choices
for choice questions, mark questions active/inactive, and reorder them. Changes take
effect immediately for families filling out the survey.

## Reports

The **Reports** page summarizes survey answers:

- **Answer summary** — for each question, a tally of each answer with counts (and a
  little bar), tagged as a registration or lottery question.
- **All responses** — every individual response (question, answer, respondent,
  grade, and a link to the family). Filter by question, and **Export CSV** to open
  the results in a spreadsheet.

This is the quickest way to answer questions like "how many families want the
afternoon kindergarten session?" or "which languages are most requested?"
