# Admin Staff Guidebook

For the enrollment office. This explains how to use the **admin portal** — no
technical background needed.

The admin portal lives at **`https://enrollment.renacademy.org/admin`** and can
only be opened from approved locations (usually the school office network). If the
page won't load from home, that's expected — ask IT about approved access.

## Guides

1. **[Getting started](getting-started.md)** — signing in and a tour of the menu.
2. **[Students & families](students-and-families.md)** — search, view a family, edit
   students, change a status, add notes.
3. **[The lottery & the school year](lottery-and-year.md)** — the enrollment
   dashboard, running the lottery, the returning-student roster, starting a new year.
4. **[Paperwork, surveys & reports](documents-surveys-reports.md)** — uploading
   registration packets, editing survey questions, viewing survey results.
5. **[Settings & staff accounts](settings-and-admins.md)** — enrollment phase,
   grade capacity, email notifications, and adding admin logins.

## The big picture

Families apply through the public site. Each student moves through a series of
**statuses** (e.g. *Awaiting Lottery → Offer Extended → Awaiting Paperwork →
Registered*). The office uses this portal to run the lottery, extend and track
offers, send reminder emails, manage the returning-student roster, and provide the
registration paperwork. Most of what you'll do is on the **Dashboard** and the
**Search / family** pages.

> **A note on safety.** Actions like *Start a new lottery year* and *Run official
> lottery* are one-way and clearly marked. When in doubt, read the on-screen
> warning and check with IT before confirming.
