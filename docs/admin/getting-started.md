# Getting started

## Signing in

1. Go to **`https://enrollment.renacademy.org/admin`**.
2. Enter your admin **username** and **password** and select **Log in**.

If the page doesn't load at all, you're probably on a network that isn't approved
for admin access (for security, the admin area is limited to specific locations).
Try from the office, or contact IT.

Don't have a login yet? An existing admin can create one for you from
**Settings → Admin accounts** (see [Settings & staff accounts](settings-and-admins.md)).
Your session stays active for the workday and then asks you to sign in again.

## The menu

Every admin page has the same navigation row near the top:

| Menu item | What it's for |
|---|---|
| **Dashboard** | The enrollment-by-grade overview: how many students are in each status, and how many seats are open. Your home base. |
| **Search** | Find a family by a student's name. |
| **Reports** | Survey results — summary tallies and every individual response, with CSV export. |
| **Roster** | The list of students currently attending (used to match returning families). |
| **Run Lottery** | Preview and run the enrollment lottery, and view past runs. |
| **Survey Questions** | Edit the questions families answer. |
| **Paperwork** | Upload the registration PDF packets families download. |
| **Settings** | Enrollment phase, grade capacity, email notifications, and staff accounts. |

## A quick tour of the Dashboard

The Dashboard shows a grid: **one row per status, one column per grade (K–9)**,
plus a **Total** column.

- **Click any number** to see the exact students behind it (opens a filtered list).
- **Click a grade heading** to see everyone in that grade.
- Select the small **ⓘ** next to a row name for a plain-English explanation of what
  that status means.
- **Max Slots** is your capacity per grade; **Open Slots** is what's left after
  counting everyone currently holding a seat.

From a filtered list, click a family to open their page and take action.
